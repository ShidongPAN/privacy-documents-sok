# Privacy Documents SoK

This repository accompanies the paper:

> **SoK: From Generation to Consumption of Privacy Documents in Software Systems**  
> Network and Distributed System Security Symposium (NDSS), 2027.

## Contents

The repository provides:

- the complete list of venues considered during paper collection;
- bibliographic metadata for the 290 papers included in the SoK;
- coding annotations for the analyzed papers.
